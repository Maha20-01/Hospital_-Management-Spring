# 🏥 Hospital Management System (Spring Boot)

A backend application built using **Spring Boot** to manage hospital operations.  
It provides secure REST APIs with **JWT authentication** and supports full **CRUD operations** for patient management.

---

## 📌 Features

- 👤 User Registration & Login
- 🔐 JWT Authentication & Authorization
- 🛡️ Secure REST API Access
- 🏥 Patient Management System
    - Create Patient
    - View Patient Details
    - Update Patient Information
    - Delete Patient Records

---

## 🛠️ Tech Stack

- Java
- Spring Boot
- Spring Security
- JWT (JSON Web Token)
- Spring Data JPA
- MySQL
- Maven
